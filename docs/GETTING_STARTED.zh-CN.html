项目是什么

What is XRDBench?

XRDBench 是一个模型无关的 XRD 结果评测基准。传统检索软件、深度学习模型和 agent 都可以接入：它们读入谱图，输出晶体结构 CIF，XRDBench 完成结构核对与打分。

XRDBench is a model-agnostic benchmark for XRD results. Search software, deep-learning models, and agents can all participate: they read patterns, output crystal CIFs, and XRDBench validates and scores the results.

安装

Installation

  1. 克隆项目和 XRDinspector 子模块。Clone the project and the XRDinspector submodule.
    git clone --recurse-submodules https://github.com/Asterbin/xrdbench.git
cd xrdbench
  2. 创建 Python 3.9+ 环境并安装。Create a Python 3.9+ environment and install the packages.
    conda create -n xrdbench python=3.11 -y
conda activate xrdbench
pip install -e ./XRDinspector -e .
  3. 检查命令。Verify the commands.
    xrdbench --help
xrdbench-prepare --help

读取 XRD 数据

Read XRD data

谱图统一为 10–80° 2θ、0.01° 步长、7,001 个点；强度经过基线处理和面积归一化。

Patterns share a 10–80° 2θ grid at 0.01° spacing (7,001 points), with baseline treatment and area normalization.

import json
from pathlib import Path
import h5py

root = Path("datasets/rruff")
record = json.loads((root / "manifest.jsonl").read_text().splitlines()[0])
with h5py.File(root / record["input"]["archive"], "r") as h5:
    two_theta = h5["two_theta_deg"][:]
    intensity = h5[record["input"]["dataset"]][record["input"]["index"]]
print(record["sample_id"], two_theta.shape, intensity.shape)
注意：训练集可包含标签；隐藏测试集不能将 ground_truth 或真解 CIF 交给模型。
Important: labels may be available for training. Never expose ground_truth or reference CIFs from a hidden test set to a model.

让模型输出 CIF

Make your model output CIF

标准 CIF 应为 UTF-8 文本，包含晶胞长度/角度、元素种类和原子分数坐标。模型可直接写文件、返回 CIF 文本，或返回 pymatgen Structure 后导出。

A standard CIF is UTF-8 text containing cell lengths/angles, species, and fractional atomic coordinates. A model may write a file directly, return CIF text, or export a pymatgen Structure.

from pymatgen.io.cif import CifWriter

# structure is a pymatgen.core.Structure object
CifWriter(structure).write_file("outputs/cifs/sample-phase-1.cif")

Helper domo/make_submission.py 提供现有 CIF、pymatgen Structure、CIF 文本和 legacy ID 的完整示例。 provides complete examples for existing CIFs, pymatgen Structures, CIF text, and legacy IDs.

写入 submission.jsonl 并评测

Write submission.jsonl and evaluate

一行一个样本。单相提交一个 CIF；多相提交 2–3 个 CIF。

Write one sample per line. Submit one CIF for a single phase and two or three CIFs for a mixture.

{"sample_id":"rruff-single-000000","prediction":{"structure_files":["outputs/cifs/one.cif"]}}
{"sample_id":"rruff-multi-000000","prediction":{"structure_files":["outputs/cifs/a.cif","outputs/cifs/b.cif"]}}
xrdbench evaluation/hidden-test.jsonl outputs/submission.jsonl \
  --data-root . \
  --output outputs/report.json

评测器读取预测 CIF 和隐藏真解 CIF，依据晶胞、元素与原子坐标进行一对一匹配。多报相降低 precision，漏相降低 recall；所有相恰好匹配时 exact_match 才为 true。

The evaluator reads predicted and hidden-reference CIFs and makes one-to-one matches using cell, species, and atomic coordinates. Extra phases lower precision, missing phases lower recall, and exact_match is true only when every phase matches.

理解评测报告

Read the evaluation report

`report.json` 包含汇总分数和逐样本诊断。汇总用于比较模型；逐样本结果用于定位漏相、误报或无效 CIF。

`report.json` contains aggregate scores and per-sample diagnostics. Use the summary to compare models and the sample records to locate missing phases, extra phases, or invalid CIFs.

{
  "summary": {
    "identification.multi": {
      "coverage": 1.0,
      "exact_match_rate": 0.52,
      "macro_precision": 0.80,
      "macro_recall": 0.73,
      "macro_f1": 0.75
    }
  },
  "samples": [{"validation_mode": "cif_structure_match"}]
}
Field含义Meaning
coverage完成预测的样本比例Fraction of samples with a prediction
exact_match_rate全部相一对一正确的比例Fraction with every phase matched one-to-one
macro_f1逐样本 F1 的平均Mean of per-sample F1 values
validation_mode应为 cif_structure_matchShould be cif_structure_match for CIF submissions

精修评测

Refinement evaluation

精修模型输出的是计算谱而非 CIF。实验谱和计算谱均为两列：two_theta_deg intensity。

A refinement model outputs a calculated pattern rather than a CIF. Both experimental and calculated files are two-column: two_theta_deg intensity.

xrdinspector refine experimental.xy calculated.xy

Rp 与 Rwp 越低越好，相关系数越接近 1 越好。分数衡量谱图拟合质量，不能单独证明结构的化学正确性。

Lower Rp and Rwp are better, while correlation should approach 1. The score measures pattern agreement; it does not by itself prove chemical correctness.

为什么不直接比较 CIF 文本？

Why not compare CIF text?

同一结构可有不同排版、origin choice 或 cell setting。XRDBench 比较解析后的结构，因此这些文本差异不会造成误判。

The same structure can have different formatting, origin choices, or cell settings. XRDBench compares parsed structures, preventing false mismatches from textual differences.
