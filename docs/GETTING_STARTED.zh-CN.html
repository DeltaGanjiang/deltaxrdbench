项目是什么

XRDBench 是一个面向 X 射线衍射（XRD）结果的可复现评测基准。任何模型都可以接入：传统数据库检索、机器学习模型、LLM agent 或自定义规则程序。模型只需要读取谱图，并写出规定格式的 JSONL 预测文件。

任务输入真解指标
单相识别一条 XRD 谱图一个规范 phase IDAccuracy / exact match
多相识别一条混合 XRD 谱图2–3 个 phase ID 的集合Precision、Recall、F1、exact match
精修实验谱与计算谱不要求结构真解Rp、Rwp、相关系数、XRDinspector score

多相样本最多三个相，且每个相的混合比例均不低于 10%。phase ID 数量就是该样本的晶相数量。

安装

获取项目

git clone --recurse-submodules https://github.com/Asterbin/xrdbench.git
cd xrdbench

如果忘记使用 --recurse-submodules，补运行：

git submodule update --init --recursive

创建环境

conda create -n xrdbench python=3.11 -y
conda activate xrdbench
pip install -e ./XRDinspector -e .
xrdbench --help
xrdbench-prepare --help

命令不在 PATH 时可使用 python -m xrdbench.cli --help 和 python -m xrdbench.prepare --help。

下载数据集

大型 HDF5 数据不会随 git clone 提供。请从 GitHub Releases 下载后解压到 datasets/。

前往 GitHub Releases 下载数据集 
datasets/
├── mp500/   # 模拟：10,000 单相 + 30,000 多相
├── rruff/   # 实验：结构–谱图对 + 10,000 多相
└── opxrd/   # 实验：结构–谱图对 + 10,000 多相

每个目录均包含 patterns.h5、manifest.jsonl 和 structures/。请记录所用 Release 版本和校验和，保证训练与评测可复现。

读取一条谱图

所有谱图统一到 10–80° 2θ、0.01° 步长，共 7,001 个点。patterns.h5 保存数值，manifest.jsonl 将样本 ID 映射到 HDF5 行和标签。

import json
from pathlib import Path
import h5py

root = Path("datasets/rruff")
record = json.loads((root / "manifest.jsonl").read_text().splitlines()[0])

with h5py.File(root / record["input"]["archive"], "r") as h5:
    two_theta = h5["two_theta_deg"][:]
    intensity = h5[record["input"]["dataset"]][record["input"]["index"]]

print(record["sample_id"], record["task"])
print(two_theta.shape, intensity.shape)  # (7001,), (7001,)
重要：测试集的 ground_truth 只能由评测端保存，不能提供给模型。公开给模型时只提供谱图、sample ID 和允许使用的元数据。

提交模型结果

预测文件为 UTF-8 JSONL：每行一个样本，且 sample_id 必须对应数据集。单相只能提交一个 ID；多相提交无序 ID 集合。

{"sample_id":"rruff-single-000000","prediction":{"phase_ids":["RRUFF:R120044"]}}
{"sample_id":"rruff-multi-000000","prediction":{"phase_ids":["RRUFF:R120044","RRUFF:R040120"]}}

多报相会降低 precision，漏相会降低 recall，只有完整集合一致才算 exact match。漏交样本会记为 missing_prediction 并按零分进入汇总。

运行识别评测

xrdbench path/to/evaluation-dataset.jsonl submission.jsonl --output report.json

report.json 的 summary 用于比较模型；samples 是逐样本诊断结果。

  • coverage：实际完成预测的样本比例。
  • exact_match_rate：预测相集合与真解完全相同的比例。
  • macro_f1：逐样本 F1 的平均值。

精修评测

精修输入为实验谱和计算谱，两者均是两列文本：two_theta_deg intensity。

xrdinspector refine experimental.xy calculated.xy

输出的 Rp、Rwp 越低越好，correlation 越接近 1 越好。score 是 0–100 的连续质量分数。它衡量谱图一致性，不单独证明结构的物理正确性。

自己重建数据（高级）

xrdbench-prepare rruff RRUFF.db datasets/rruff --mixtures 10000 --seed 20260720
xrdbench-prepare mp500 MP500.db datasets/mp500 --single-count 10000 --mixtures 30000 --seed 20260720
xrdbench-prepare opxrd-json opxrd datasets/opxrd --mixtures 10000 --seed 20260720

固定 --seed 可以复现实验。生成的大型数据请通过 GitHub Releases、对象存储或 DOI 归档发布，而不是直接提交到 Git。

常见问题

找不到 patterns.h5

数据集不在 Git clone 内，请从 Releases 下载并解压到 datasets/。

为什么用 phase ID，而不是直接比较 CIF？

同一结构可因 CIF 排版、origin choice 或 cell setting 不同而文本不同。稳定的 canonical phase ID（例如 MP:mp-123、RRUFF:R120044）可以避免误判。

最快的跑通方式

  1. 从 Release 下载一个数据集；
  2. 用“读取一条谱图”代码检查安装；
  3. 生成几个 JSONL 预测；
  4. 运行评测并保存 report.json。
